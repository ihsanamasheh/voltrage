# Voltrage

You are an expert UI/UX designer and senior frontend engineer. Build a production-ready, fully responsive landing page for a new premium protein and sports nutrition brand using the attached assets (logo, product images, lifestyle photos, finalized text, and page hierarchy). Do not generate or modify content—focus solely on presentation and user experience. The design should be modern, premium, minimalistic, and visually cohesive, communicating trust, quality, and performance through strong visual hierarchy, generous whitespace, clean grid layouts, excellent typography, and subtle micro-interactions. Aim for the design quality of premium DTC brands such as Apple, Gymshark, and Transparent Labs, while maintaining a unique identity. Avoid clutter, excessive colors, gradients, heavy shadows, flashy animations, glassmorphism, and generic e-commerce layouts. Ensure pixel-perfect responsiveness across desktop, tablet, and mobile with fluid layouts, optimized image placement, semantic HTML, accessibility best practices, and fast loading performance. The final result should feel polished, aesthetically pleasing, and ready for production.
